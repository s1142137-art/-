# 誰是殺手 - 遊戲說明

## 遊戲簡介
這是一個基於HTML5 Canvas開發的多人推理生存遊戲，無需後端伺服器，直接在瀏覽器中運行。

## 功能特點

### 遊戲角色
- **殺手 (🔪)**: 可以隨機殺害其他玩家（70%成功率）
- **警長 (👮)**: 配有6發子彈的手槍，可擊斃殺手，但誤殺平民會死亡並掉落槍枝
- **平民 (👤)**: 找出殺手並報告警長，可撿起警長掉落的槍枝

### 遊戲機制
- 10位玩家中包含1位殺手、1位警長、8位平民
- 遊戲時間限制：3分鐘
- 即時位置同步與互動系統
- 擊殺確認機制，防止誤操作

### 操作方式
- **WASD**: 移動角色
- **滑鼠**: 控制視角方向
- **左鍵點擊**: 攻擊/射擊
- **E鍵**: 撿起地上的槍枝

### 遊戲介面
- 角色顯示區域（頂部中央）：顯示當前角色
- 計時器（頂部右側）：顯示剩餘時間
- 彈彈藥顯示（底部右側）：警長專用，顯示剩餘子彈
- 血條（底部左側）：顯示生命值
- 小地圖（右上角）：顯示所有玩家位置
- 準心：畫面中央的十字準心
- 互動按鈕：靠近其他玩家時顯示攻擊選項

### 勝利條件
- **好人陣營獲勝**：警長擊斃殺手
- **殺手獲勝**：時間結束前殺死所有平民，或時間到期時仍有殺手存活

### 技術特色
- 純前端實現（HTML + CSS + JavaScript）
- 使用HTML5 Canvas渲染遊戲畫面
- Pointer Lock API實現滑鼠視角控制
- 網格地圖系統
- 即時碰撞檢測與互動系統
